מקריא טקסט עברי - אפליקציית PWA

העלאה ל-GitHub Pages (חינם):
1. ב-github.com: New repository, שם לדוגמה hebrew-reader, Public.
2. Add file > Upload files, גרור את כל הקבצים מהתיקייה הזו (index.html, manifest.webmanifest, sw.js והאייקונים), ואז Commit.
3. Settings > Pages > Source: Deploy from a branch > Branch: main, תיקייה: / (root) > Save.
4. אחרי דקה-שתיים הכתובת תהיה https://<שם-המשתמש>.github.io/hebrew-reader/
5. פתח אותה ב-Chrome באנדרואיד > תפריט (שלוש נקודות) > "הוסף למסך הבית" / "התקן אפליקציה".
6. הזן את מפתח ה-API באפליקציה. הוא נשמר בטלפון בלבד ואינו חלק מהקבצים.
