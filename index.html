מקריא טקסט עברי

מדביקים טקסט (או טוענים קובץ טקסט), והדף מפיק הקראה בעזרת Gemini TTS ומאפשר להאזין, לראות את המשפט המוקרא מודגש (מצב קריוקי), ולהוריד קובץ אודיו אחד.
מפיקים מפתח חינמי ב-aistudio.google.com תחת Get API key.
הדוגמאות הן ההדגמות שגוגל מפרסמת בתיעוד. ייתכן שהן באנגלית.
הגדרות מתקדמות
אם המודל לא מוכר, הדף מנסה את הפורמט הישן (generateContent) לכל שם שאינו מתחיל ב-gemini-3.8. אפשר להחליף את שם המודל בשדה למעלה.
